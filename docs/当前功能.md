# 心晴 · 当前功能

面向情绪记录、心理陪伴与自助练习的 Web 应用，支持电脑和手机使用。

## 用户端

- **账户**：注册、登录、退出，按账户保存数据，多设备登录后可读取已保存内容。
- **随心聊**：AI 陪伴对话；支持新建、切换、删除会话，保存聊天历史并恢复上次选择。
- **情绪签到**：记录心情、情绪强度和备注，推荐适合的练习。
- **技能练习**：先稳一稳、拆开一个担心、考试前的小计划；提供分步引导和练习复盘。
- **情境练习**：通过三轮模拟对话，练习向同学表达边界，提供提示、反馈并可保存总结。
- **我的记录**：查看、分类筛选、删除或清空签到与练习记录，支持导入旧版浏览器个人记录。
- **支持入口**：使用说明、侧栏轮换提醒、风险信号识别与现实求助引导。

## 管理端

- 查看、筛选、启用、停用或删除普通用户。
- 查看和删除练习记录，查看与清空对话。
- 修改侧栏提醒内容及轮换间隔，查看管理员操作日志。

## 当前限制

- 课程仅有预留目录，尚未提供正式课程。
- AI 需要服务器配置；未配置时使用明确标注的预设回应。
- 数据保存在服务器 SQLite；多设备间需刷新加载最新数据，暂不实时同步。
