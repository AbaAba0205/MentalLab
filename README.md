# 心屿交互 Demo

一个面向考试压力场景的中文心理技能练习原型。采用淡紫与浅蓝渐变、侧边栏和柔和卡片，提供完整的浏览器交互，无真实后端或 AI 接口。

## 启动

安装 Node.js 20 或更新版本，在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:5173 。无第三方运行依赖，不需要 npm install。

## 已实现

- 首页：情绪签到、近七天记录、练习入口和近期记录。
- 签到：情绪选择、困扰强度、可选事件记录、预设规则推荐。
- 三种分步练习：接地练习（含暂停与重置计时器）、想法整理、考试前的小计划。
- 复盘：强度、帮助程度和个人总结。
- 记录：浏览器本地保存、刷新恢复、分类、逐条删除与清空确认。
- 练习室分类、移动端布局、帮助资源页、数据说明。

## 数据与边界

首次访问加载两条标有“示例”的模拟记录。新记录保存在 localStorage 的 `mind-island-demo-v1`，没有上传。请使用虚构数据体验；同一浏览器的使用者可能查看本地记录，本地存储未加密。

推荐完全由预设规则生成。关键词触发的帮助页仅用于演示产品分支，可能误判或漏判，不能用作真实危机检测。Demo 没有真人值守，不会拨号、通知家长或执行专业转介。中国大陆 110/120 链接只在用户点击后交由设备处理。

这不是可供真实未成年人使用的临床或心理支持服务；实际试用前需完善专业审核、安全评估、隐私及监护流程。

## 验证

```sh
npm test
node --check app.js
```

自动测试覆盖推荐边界、预设安全分支、记录校验、损坏数据恢复及模拟数据标记。浏览器验收重点为三个练习的完整流程、计时器暂停、刷新恢复、删除确认和移动端布局。

端到端脚本为 `scripts/verify-browser.mjs`，需要另外提供 Playwright 和本机 Chrome，并先启动静态服务。运行 `node scripts/verify-browser.mjs`；若使用已有的 Playwright，可将 `PLAYWRIGHT_MODULE` 环境变量设为其 `index.mjs` 绝对路径。截图输出到被 Git 忽略的 `.demo-qa/`。此脚本使用独立浏览器会话，不操作日常浏览器记录。

## 文件

- `index.html`：应用结构。
- `styles.css`：配色、布局、插画细节与响应式样式。
- `app.js`：界面与交互流程。
- `model.js`：模拟规则与记录数据处理。
- `server.mjs`：仅监听本机的静态文件服务。
- `test/model.test.mjs`：数据与规则测试。

项目讨论背景见 `项目文档.md`；该文档中超出上述范围的功能尚未实现。
