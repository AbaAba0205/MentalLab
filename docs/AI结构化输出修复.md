# AI 结构化输出修复

日期：2026-10-17（北京时间）。

## 修改后的行为

随心聊默认向模型发送严格 JSON Schema，要求完整的 `reply` 字符串、`exerciseId`（注册训练 ID 或 null）、`needsSupport` 布尔值，并禁止额外字段。当前供应商 `https://llmapi.paratera.com` 的 `DeepSeek-V4.1-Flash` 已接受该参数；后续真实验证中的九份完整响应均符合字段要求。

提示词明确历史 assistant 消息是界面解包后的普通文字，不是输出格式示例，并说明空对象、缺失字段、错误类型和额外字段不可接受。本地继续执行回复长度、安全文字和训练资格校验；一旦模型标记需要现实支持，仍直接展示固定支持内容。

第一次校验失败后，根据具体原因附加纠正要求，再生成一次。不会把失败回复原文重新注入模型，也不会把普通文字包装成 JSON 来绕过校验。最大调用次数仍为两次。

默认 Schema 请求遇到 HTTP 400/422 时，剩余重试切换为 JSON 对象模式。也可通过 `AI_CHAT_RESPONSE_FORMAT=json_object` 显式兼容其他供应商；字段和安全校验继续生效。鉴权错误不触发格式降级。

两次模型调用共用 20 秒生成预算，单次最多 15 秒；重试只使用剩余时间，为浏览器 22 秒等待上限留出余量。情境练习保持原有调用策略。
